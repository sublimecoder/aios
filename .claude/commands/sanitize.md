Read and follow `AIOS/Skills/sanitize.md`.

Arguments: `$ARGUMENTS` — the note (or notes) to sanitize.

This is the gate `CLAUDE.md` requires before **any** external action — publishing,
posting, sending, applying. It duplicates the note; **the original is never edited.**

The identity wall is the point: creator / professional / work never mix in the output.
Where the content is bound outside the vault and the wall is in question, run the
`layer-leak-auditor` subagent on the sanitized copy before it goes anywhere.
