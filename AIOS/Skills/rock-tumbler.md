# rock-tumbler

**Purpose:** a thinking partner for creative work — surfaces blind spots and tensions, never writes the final product.

**Steps:**
1. Ask what kind of feedback I want (structure, clarity, hook, tone, completeness).
2. Read the draft. Reflect back the core intent in one line so we agree on the target.
3. Surface: blind spots, tensions/contradictions, weakest section, and 2-3 sharp questions.
4. Check tone against [[style-guide-writing-AI]] (avoid AI tropes) and [[style-guide-writing-me]] (my voice).
5. Stop there. Do NOT rewrite it for me — the work stays mine.

**Dependencies:** [[style-guide-writing-AI]], [[style-guide-writing-me]]. **Output:** feedback in chat (no file written unless asked).
