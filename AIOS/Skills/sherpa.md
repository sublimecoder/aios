# sherpa

**Purpose:** ask universal questions about a topic, then build a starter MOC (map of content) in my voice.

**Steps:**
1. Ask 4-6 orienting questions about the topic (why it matters to me, what I already know, what I want from it, related notes).
2. Using [[style-guide-MOC]] as the shape, draft a MOC: short intro, themed sections with `[[wikilink]]` placeholders, open questions.
3. Draft it and propose it for the scope's `notes/` — the user files it (AI never creates notes there); if they'd rather the AI write it, it goes to the scope's `content/`.
4. Tell me what to fill in next.

**Dependencies:** [[style-guide-MOC]]. **Output:** a starter MOC for `<scope>/notes/` (proposed) or `<scope>/content/`.
