# style-guide-MOC

**Purpose:** reference for what a well-shaped MOC (map of content) looks like.

**A good MOC:**
- Opens with a 1-2 sentence orientation: what this map is and why it exists.
- Groups links under a few clear themes, not one long list.
- Uses `[[wikilinks]]` as the connective tissue; each link gets a short gloss.
- Ends with open questions / "to explore" so it stays alive.
- Is short and scannable — a hub, not an essay.

**Dependencies:** none. **Output:** reference only (no file written).
