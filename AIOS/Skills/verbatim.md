# verbatim

**Purpose:** save an AI conversation word-for-word to a note.

**Steps:**
1. Capture the conversation exactly as-is, no editing or summarizing.
2. Add a short frontmatter header (date, topic, participants).
3. Write to a new note (default `Atlas/` or a note I name); works for existing notes too.

**Dependencies:** none. **Output:** new or named note with the full transcript.
