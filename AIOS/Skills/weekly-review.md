# weekly-review

**Purpose:** review the week and fill a new review-preview note.

**Steps:**
1. Read last week's review in `AIOS/History/reviews/` and this week's daily notes/briefs in `AIOS/History/days/`.
2. Scan open `- [ ]` tasks across the vault (excluding `archive/System Docs/`).
3. Summarize the active pipeline state (whatever this vault tracks as in-flight work).
4. Write `AIOS/History/reviews/<date> Weekly Review.md`: wins, what slipped, pipeline status, and 3-5 proposed next actions.

**Dependencies:** none. **Output:** `AIOS/History/reviews/<date> Weekly Review.md`.
